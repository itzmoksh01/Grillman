# Example: AI/ML Engineer Intern assignment (newspaper ad detection and cropping)

- `BRIEF.md`: the assignment text, verbatim from the PDF (images described, not transcribed).
- `LEADS.md`: research leads to verify (datasets, models, licences, pitfalls). Not a solution.
- `PASTE_ME_newspaper-ad-detection.md`: Grillman master prompt with the brief and leads baked in. Paste it into any strong AI, and also attach the original PDF and sample pages.

Rebuild it: `scripts/make_prompt.sh examples/newspaper-ad-detection/BRIEF.md examples/newspaper-ad-detection/LEADS.md > PASTE_ME.md`
